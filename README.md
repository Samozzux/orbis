# Orbis

Simulatore di città e di vita ambientato nel mondo reale, a partire da Chieti. Gioco Unity per **iPhone/iPad** e **web**.

- 🎮 Versione web: https://samozzux.github.io/orbis/ (attiva da M0)
- 📱 IPA: scheda **Actions** → ultima esecuzione verde di "iOS build" → **Artifacts** → `Orbis-ipa`, da installare con Sideloadly (istruzioni in `docs/07-pipeline-build-deploy.md` §4)
- 📚 Specifica: cartella [`docs/`](docs/) — si parte da [`docs/00-visione.md`](docs/00-visione.md)
- 🤖 Regole per Claude Code: [`CLAUDE.md`](CLAUDE.md)
- 📈 Avanzamento: [`docs/STATO.md`](docs/STATO.md)
